# Gestor de Pacientes

Plataforma web para digitalizar expedientes médicos y eliminar el uso de papel en consultorios.

### ¿Por qué existe?
Creada para ayudar a mi hermana a organizar la información de sus pacientes, agilizar las consultas y evitar el papeleo manual.

### Funcionalidades
- **Expedientes digitales:** Datos personales, diagnósticos, alergias y notas.
- **Alertas de recarga:** Notificación de renovación de medicamentos.
- **Historial protegido:** Las tarjetas eliminadas se ocultan de la vista pero conservan su historial en la base de datos.
- **Búsqueda rápida:** Filtro por nombre o diagnóstico.

### Tecnologías
React | Vite | Python - Flask | PostgreSQL - Supabase | Render
